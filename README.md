## 🇬🇧 English

### Introduction

This repository provides a collection of test materials (TIFF images) referenced in the **Digital Cinema System Specification Compliance Test Plan (CTP), Version 1.4.3**. These materials are intended for use in testing Digital Cinema Packages (DCPs) and playback systems against DCI specifications.

### ⚠️ Disclaimer

**Please Read Carefully:**

* **"As Is" Basis:** These materials are provided "as is" without warranty of any kind, express or implied.
* **No Guarantee of Compliance:** While efforts have been made to align with CTP 1.4.3 specifications (including 16-bit XYZ color space, Gamma 2.6 for SDR, and PQ/ST 2084 for HDR), we **do not guarantee** that these materials are fully compliant with DCI standards or that they will pass official certification tests.
* **Not Formally Tested:** These materials have **not** been formally verified by DCI or any authorized test entity.
* **Use at Your Own Risk:** The user assumes all responsibility for the use of these materials. The authors are not liable for any errors, omissions, or damages arising from their use.
* **Free for Public Use:** This project is free and open for public use. Feedback is welcome.

### ⚠️ Note on Auto-Generated DCPs

The DCPs provided in the table below are **automatically generated** using our CI/CD pipeline. 
* They have **not been manually verified** on DCI-compliant servers.
* If a DCP fails to load or play, please refer to the [DCP Generation Guide](#dcp-packaging-guide) to manually package the TIFF materials using compliant tools (e.g., easyDCP, OpenDCP, or `asdcp-test`).
* The status badges indicate whether the *generation process* succeeded, not whether the DCP is compliant.

### HDR Metadata Support

Our DCP generation scripts now support **HDR (High Dynamic Range)** content with proper metadata:
* **Automatic Detection:** Materials with "HDR" in their directory name are automatically detected.
* **CPL Extension Metadata:** For HDR content, the CPL includes an ExtensionMetadataList with the DCI HDR namespace (`http://www.dcimovies.com/schemas/2018/HDR-Metadata`), specifying **ST 2084 (PQ)** as the EOTF.
* **Manual Usage:** Use the `--hdr` flag when running the generation scripts manually:
  ```bash
  python3 scripts/generate_dcp.py --image input.tiff --output dcp_output --hdr
  ```

### DCP Packaging Guide

To use these materials in a digital cinema environment, you must package the TIFF files into a Digital Cinema Package (DCP).

#### Tools

* **GUI Tools:**
  * [OpenDCP](https://opendcp.net/) (Free, Open Source)
  * [DCP-o-matic](https://dcpomatic.com/) (Free, Open Source)
* **Command Line Tools:**
  * [asdcplib](http://www.cinecert.com/asdcplib/) (Standard reference implementation)
  * `opendcp_mxf`, `opendcp_xml`

#### Basic Workflow (OpenDCP Example)

1. **Download:** Download the TIFF file from the table above.
2. **Convert to JPEG 2000:**
   * Open OpenDCP -> "JPEG 2000" tab.
   * Input: Select your TIFF file.
   * Profile: Choose "Cinema 2K" or "Cinema 4K" matching the image resolution.
   * Frame Rate: Set to 24 (or as required).
   * Click "Convert" to generate `.j2c` file.
3. **Wrap to MXF:**
   * Go to "MXF" tab.
   * Type: "Picture".
   * Input: Select the `.j2c` file.
   * Output: Save as `.mxf`.
4. **Create DCP (XML):**
   * Go to "DCP" tab.
   * Title: Enter a CPL title (e.g., `DCI_White_Steps_TST_F_2K_20251129_SMPTE_OV`).
   * Annotation: Description of the package.
   * Picture: Add the `.mxf` file.
   * Click "Create DCP".

### DCP 打包指南

要在数字影院环境中使用这些素材，您必须将TIFF文件打包成数字电影包 (DCP)。

#### 工具

* **图形界面工具 (GUI):**
  * [OpenDCP](https://opendcp.net/) (免费，开源)
  * [DCP-o-matic](https://dcpomatic.com/) (免费，开源)
* **命令行工具 (CLI):**
  * [asdcplib](http://www.cinecert.com/asdcplib/) (标准参考实现)
  * `opendcp_mxf`, `opendcp_xml`

#### 基本工作流 (OpenDCP 示例)

1. **下载:** 从上表下载 TIFF 文件。
2. **转换为 JPEG 2000:**
   * 打开 OpenDCP -> "JPEG 2000" 标签页。
   * Input (输入): 选择您的 TIFF 文件。
   * Profile (配置文件): 根据图像分辨率选择 "Cinema 2K" 或 "Cinema 4K"。
   * Frame Rate (帧率): 设置为 24 (或按需设置)。
   * 点击 "Convert" 生成 `.j2c` 文件。
3. **封装为 MXF:**
   * 进入 "MXF" 标签页。
   * Type (类型): 选择 "Picture" (画面)。
   * Input (输入): 选择刚才生成的 `.j2c` 文件。
   * Output (输出): 保存为 `.mxf` 文件。
4. **创建 DCP (XML):**
   * 进入 "DCP" 标签页。
   * Title (标题): 输入 CPL 标题 (例如 `DCI_White_Steps_TST_F_2K_20251129_SMPTE_OV`)。
   * Annotation (注释): 输入包的描述。
   * Picture (画面): 添加 `.mxf` 文件。
   * 点击 "Create DCP"。
